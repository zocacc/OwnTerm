# I00 — Consolidar documentação do MVP

**Status:** planned  
**Dependências:** nenhuma

## Objetivo

Versionar o contexto, o glossário, as specs, ADRs e o backlog que definem o MVP.

## Escopo

- [ ] Registrar linguagem canônica em `CONTEXT.md`.
- [ ] Criar escopo, arquitetura, IPC, segurança e specs de capacidade.
- [ ] Criar ADRs para limites difíceis de reverter.
- [ ] Criar épicos, issues e sub-issues ordenados.

## Fora do escopo

Scaffold, código de produto e publicação remota de issues.

## Critérios de aceite

- [ ] Toda capacidade obrigatória do contexto possui spec e issue rastreável.
- [ ] Decisões aceitas não conflitam com o glossário ou com o threat model.
- [ ] Backlog explicita dependências e testes.

## Testes

- [ ] Links Markdown internos e referências de IDs validados.
